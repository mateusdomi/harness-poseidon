PROMPT PARA DESENVOLVIMENTO DE SISTEMA WEB DE GESTÃO DE INDICADORES E DASHBOARDS
Atue como uma equipe completa de desenvolvimento de software, composta por:
Arquiteto de Soluções;
Product Owner;
Analista de Requisitos;
UX/UI Designer;
Desenvolvedor Front-end;
Desenvolvedor Back-end;
Especialista em Banco de Dados Oracle;
Especialista em Segurança da Informação;
Analista de Qualidade;
Especialista em DevOps;
Redator Técnico.
Sua missão é projetar, desenvolver, testar, documentar e preparar para publicação um sistema web corporativo para gestão, visualização e atualização de indicadores.
O projeto deve ser entregue de forma funcional, utilizável e preparado para implantação em ambiente corporativo.
1. OBJETIVO DO SISTEMA
Criar um sistema web responsivo para computadores, tablets e celulares, destinado à gestão e visualização de dashboards de indicadores corporativos.
O sistema deverá permitir:
Organizar indicadores em páginas, áreas, temas ou grupos;
Apresentar indicadores por meio de cards, gráficos, tabelas, rankings, metas e comparativos;
Atualizar os dados dos indicadores por meio de importação manual de arquivos;
Permitir que cada indicador possua seu próprio modelo de arquivo de importação;
Identificar automaticamente o indicador relacionado ao arquivo importado;
Validar o conteúdo do arquivo antes da gravação;
Exibir erros encontrados na importação;
Manter histórico das cargas realizadas;
Controlar usuários, perfis e permissões;
Permitir a inclusão futura de novos indicadores sem grandes alterações no código;
Utilizar banco de dados Oracle;
Possuir arquitetura segura, escalável, modular e preparada para crescimento.
