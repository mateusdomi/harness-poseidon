# Harness Poseidon

Fábrica autônoma de software — um agente chefe coordena agentes de IA que desenvolvem projetos reais, sob governança, gates e auditoria.

## Estrutura do monorepo

- `frontend/` — interface web (React + TypeScript + Vite)
- `docs/frontend/` — documentação viva do frontend (CURRENT_STATE, PROGRESS, DECISIONS, HANDOFF_API, SCREENS)

## Branches

- `main` — versão estável e homologada. Merge apenas com autorização humana explícita.
- `develop` — integração contínua de todo o desenvolvimento.

Não são permitidas branches adicionais.
